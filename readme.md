# Family Cure Mission Website

A modern, fully responsive website for Family Cure Mission (FCM) - a person-centered care organization in Uganda.

## Features

- ✅ Fully responsive design (mobile, tablet, desktop)
- ✅ Modern UI/UX with smooth animations
- ✅ Interactive elements and forms
- ✅ SEO optimized
- ✅ Accessibility compliant
- ✅ Fast loading performance
- ✅ Cross-browser compatible

## Color Scheme

- **Dark Green**: #0B5345 (Primary)
- **Red**: #C0392B (Health Services)
- **Dark Blue**: #1B4F72 (Secondary)
- **Orange**: #E67E22 (Economic Empowerment)

## Pages Included

1. **Home** - index.html
2. **About Us** - about.html
3. **Services** - services.html
4. **Psychotherapy** - psychotherapy.html
5. **Health Services** - health-services.html
6. **Economic Empowerment** - economic-empowerment.html
7. **Our Team** - team.html
8. **2026 Interventions** - interventions-2026.html
9. **Contact** - contact.html

## Installation

1. **Extract the files** to your web server directory
2. **Replace** `images/logo.png` with your actual logo
3. **Update** contact information in all HTML files:
   - Phone numbers
   - Email addresses
   - Physical address
4. **Customize** content as needed
5. **Test** all pages in multiple browsers
